# kirjasto-harjoittelu-2.0
A newer version of an older project. <br>
**API USED:** https://api.kirjastot.fi/v4/library

## Description
A small project, which uses the aforementioned API to give information about every Finnish library. If available, following info (in finnish) is included:

1. Name
2. Picture of the library
3. Description
4. Zipcode
5. City and street via Google Maps
6. Links related to the library
